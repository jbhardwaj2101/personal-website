# Jagjot Bhardwaj — Personal Website

Premium Editorial static website. No build tools needed.

## Preview
Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and open http://localhost:8000.

## Publish with Vercel
1. Create a GitHub repository and upload the contents of this folder (not the ZIP).
2. Sign in to https://vercel.com using GitHub, select Add New > Project, import your repository.
3. Set Framework Preset to **Other**, leave Build Command empty, and set Output Directory to `.` if prompted.
4. Deploy. Vercel will give you a public `*.vercel.app` URL.
5. Purchase a personal domain if desired and add it under Project > Settings > Domains; follow Vercel's DNS instructions.
6. In Google Search Console (https://search.google.com/search-console), verify ownership of your domain, inspect the homepage URL and request indexing.
7. After choosing your final domain, add an absolute canonical URL, absolute Open Graph image URL, and sitemap.xml for the final domain. Do not submit a sitemap with a placeholder domain.
